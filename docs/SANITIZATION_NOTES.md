# Sanitization and repair notes (release build, 2026-07-29)

Every shipped script derives from a verified canonical source in the research
repository (including its revision workspaces and a byte-identical-verified
earlier internal release candidate). **Numerics, algorithms, seeds and
constants are preserved verbatim**; only path wiring, CLI/environment
plumbing and one stale docstring were changed. This file records every
repair. (Legacy file and column names containing "risk" are explained in
docs/TERMINOLOGY.md.)

## Conventions introduced

* `scripts/figures/common/_clean_paths.py` -- single source of path truth:
  release root auto-discovery (nearest ancestor with `scripts/` +
  `configs/`), `SCORCH_DATA_DIR` (deposit root, default `scorch_data/`),
  `SCORCH_OUT_DIR` (default `reproduced/`), and `data_file(name, *subdirs)`
  which resolves files inside the deposit layout (catalogs/, gridded/,
  lgcp/, power_law/, validation_kfold/, validation_station/, ...).
* All outputs go under `reproduced/`; no script writes into the deposit,
  the frozen assets, or the code tree.
* The release bootstrap block at the top of reused figure scripts was
  retargeted from the earlier candidate's layout markers (`code/` +
  `data/`) to this release's layout (`scripts/` + `configs/`), and its
  `sys.path` insert now points at `scripts/figures/common/`.

## Post-release-build wording corrections (kept in sync with this file)

The per-file repairs above cover the initial release build. Two later
correction passes changed GENERATED WORDING only - no numerics, no
algorithms, no seeds, and no scientific data were touched:

* The four LGCP diagnostic maps' displayed title in
  `scripts/lgcp/spatial_risk_lgcp_model_diagnostics.R` was corrected from
  "Predicted centroid risk (fitted intensity x 1e6)" to "Predicted
  centroid concentration (fitted intensity x 1e6)"; the diagnostics were
  re-executed against the deposited `lgcp/` inputs and the refit
  parameter tables verified byte-identical to the deposit.
* The same script's console/run-log header now reads "SCORCH
  centroid-concentration LGCP"; its generated summary Markdown, the
  generated cross-validation reports (the `RISK_ZONE_CV_REPORT.md`
  heading now says "Concentration-zone ... cross-validation", and the
  k-fold explainers) use centroid-concentration wording; and the
  legacy explanatory "box" prose in public documentation and generated
  reports became "grid cell" (legacy wording retired). Legacy FILE names
  and stored COLUMN names are retained throughout (see
  docs/TERMINOLOGY.md).

* V7 repairs: (1) OUTPUT ISOLATION - 13 scripts (the fig02 panels and
  assembly, fig03 panels and composite, fig08, fig09, fig11, fig12, the
  A.2 and A.3 producers, the S.2 assembly, and the LGCP variant-3
  extractor) resolved a hardcoded repository-root `reproduced/` path from
  their release bootstrap instead of the requested output directory; all
  now alias the central `_clean_paths.GENERATED_DIR` helper (honours
  `SCORCH_OUT_DIR`), `scorch reproduce` accepts `SCORCH_OUT_DIR` as its
  out-dir default, the driver suppresses interpreter bytecode caches, and
  `tests/test_output_isolation.py` guards the contract. (2) The Figure 2
  panel (b) axis labels moved from legacy "Grid Boxes" wording to
  "Grid Cells" (see docs/TERMINOLOGY.md; this corrected Figure 2 was
  DEPLOYED into the WORKING manuscript on 2026-07-30 in the
  advisor-directed G2 pass, deployed embed `62c20697...`). (3) The
  SOURCE_DOWNLOAD_GUIDE CDS-key example was rewritten without angle
  brackets (`REPLACE_WITH_YOUR_PERSONAL_ACCESS_TOKEN`) so the release
  archive scan's strict placeholder rules pass on the real archive.
